Expand description

Robot-side protocol, driven by a host worker or explicitly between firmware iterations. The first record opens the session. A retained payload must be moved into protocol-owned storage.

fn send(&mut self, record: CuTelemetryRecord<'_>) -> CuResult<()>

Accept one borrowed record with bounded, nonblocking work.

Provided Methods§

Source

fn poll(&mut self, _mode: TxMode) -> CuResult<Option<CuTime>>

Perform bounded, nonblocking work and return the next absolute wakeup on the transport clock supplied at setup. The worker may also poll early after receiving a record. In draining mode, stop periodic repetition and return None when pending work is done.
