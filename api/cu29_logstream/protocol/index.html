Module protocol 

Source
Expand description

Native capture records exchanged between a generated runtime and a live twin.

A protocol instance serves one session. It owns packetization, integrity, reassembly and duplicate suppression. Both peers use the matching application and capture encoding. Each byte slice is one complete native payload.

Ground-side protocol. Deliver one session header before its records, CopperLists in ID order starting at zero (or report an initial gap), and snapshots at their original boundaries. The callback may borrow directly from reassembly storage and its first error must terminate delivery.
