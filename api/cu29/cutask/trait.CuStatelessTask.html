Expand description

A transform task whose per-CopperList callbacks do not mutate the task instance.

Stateless tasks have the same input/output shape as CuTask, but preprocess, process, and postprocess receive &self. This makes the task safe for runtimes to invoke for different CopperLists concurrently. Construction, start, stop, and Freezable::thaw remain exclusive lifecycle operations.

Implementations must be Send and Sync. Any shared state reachable through self must preserve deterministic behavior when callbacks overlap.
